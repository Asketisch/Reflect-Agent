# i18n-extract

提取用户可见字符串到 i18n 资源,支持多语言。

## 流程

1. **扫描**:找所有用户可见字符串(UI 文案 / 错误消息 / 日志里的用户提示)。
   - 注意:`println!` / `eprintln!` / TUI widget text / API error message。
2. **标记**:用 gettext 风格 `t!("key")` 或 ICU 格式包裹,key 用语义命名。
3. **提取**:跑提取工具生成 `locale/en.json` 等模板,翻译填其他语言。
4. **复数 / 性别**:用 CLDR 复数规则,不要手拼 "s"。
5. **验证**:切语言跑一遍,确认无遗漏硬编码。

## 注意

- 日志(开发者看)通常不 i18n;用户可见(错误 toast)才 i18n。
- 不要拼接翻译片段(语序不同);用占位符模板 `{name}`。
