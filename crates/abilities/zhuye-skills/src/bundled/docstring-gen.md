# docstring-gen

为函数 / 模块补文档注释,解释"为什么"而非"做什么"。

## 原则

- **说意图**:解释设计决策、约束、边界,不复述代码逻辑。
- **标契约**:公开 API 必须注明参数含义、返回值、错误条件、panic 场景。
- **给例子**:非平凡 API 附 `# Examples`(会跑 doctest)。
- **语言**:遵循项目规范(本项目用标准中文注释,Rust 标识符保留英文)。

## 检查清单

- [ ] 公开项(`pub`)都有 `///`?
- [ ] 模块有 `//!` 概述?
- [ ] 复杂逻辑有行内 `//` 解释"为什么"?
- [ ] 没有"返回 X 的 X 函数"这类冗余注释?
