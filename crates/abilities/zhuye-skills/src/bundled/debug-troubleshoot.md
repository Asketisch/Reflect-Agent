# debug-troubleshoot

系统化调试技能。当遇到 bug、错误、崩溃或意外行为时使用。

## 流程

1. **复现**:确认能稳定复现;记录精确触发条件(输入 / 环境 / 版本)。
2. **定位**:读错误栈 + 最近改动(`git log -p` / `git diff`),缩小可疑范围。
3. **假设**:提出 1-2 个最可能的根因假设,按概率排序。
4. **验证**:用最小改动验证假设(加日志 / 二分注释 / 最小复现脚本)。
   - 一次只改一个变量,避免混淆因果。
5. **修复**:确认根因后修最小必要改动;补充回归测试覆盖原失败场景。
6. **复盘**:若根因是设计缺陷,记录教训(考虑 hindsight memory)。

## 麦凯布规则

不要在未理解根因前"碰运气式"改代码。先证明假设,再动手。
