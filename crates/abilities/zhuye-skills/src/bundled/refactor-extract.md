# refactor-extract

安全重构技能:提取函数 / 抽接口 / 消除重复,不改变外部行为。

## 原则

- **行为保持**:重构前后测试集全绿;无测试时先补特征化测试(characterization test)。
- **小步快走**:每次提交只做一种重构(提取 / 内联 / 重命名),便于回退。
- **先读后改**:理解现有结构 + 调用点再动;用 `grep` 找全引用。

## 常见手法

- **提取函数**:长方法里选出"做一件事"的代码段,提取为命名函数。
- **提取接口**:多个调用方依赖同一组方法时,抽 trait 让实现可替换。
- **内联**:间接层无价值时(单实现 / 透传),内联回调用方。
- **搬移**:函数离数据 / 调用方太远时,搬到更合适的模块。

每步后跑 `make test-changed` + `make check`,绿了再下一步。
